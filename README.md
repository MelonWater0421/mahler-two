# Mahler 2 · 《复活》全景声部与复调导览

面向音乐爱好者的古斯塔夫·马勒《第二交响曲“复活”》（Auferstehung）旗舰级双语互动总谱导览：五个乐章的原声定位、WebAudio 复调积木解剖室、声部实时雷达提示、总谱小节号与宏观交响线索。桌面与移动端全自适应响应式设计。

内置西蒙·拉特尔爵士（Sir Simon Rattle）率领柏林爱乐乐团（Berliner Philharmoniker）2010年柏林爱乐大厅经典实况录音，页面打开即可独立离线/在线播放，无需任何后端或外部插件。

- **在线预览**: 直接通过 GitHub Pages 访问
- **本地启动**: `python3 serve.py 8080`（支持 HTTP 206 断点续传与平滑拖动）
- **功能特性**:
  - 190 个精细总谱节点（25–35秒密度，中英完整对称）
  - 600 点实测音频 RMS 振幅波形拖拽与实时悬浮时间提示
  - WebAudio 多轨复调合成器（声部静音/独奏、实时钢琴卷帘与音符高亮发光）
  - 五大乐器声部（弦乐、木管、圆号、重型铜管、打击乐/合唱/管风琴）实时导听雷达
  - 快捷键盘控制：Space 播放/暂停，←/→ 快退/快进 5 秒，Esc 停止 MIDI 试听
